= 拡張AsciidocをWordに変換するスクリプト

Asciidocは便利ですが所々使いにくいと感じている所を解消してWordに出力するスクリプトを作りました
全てのAsciidocの構文には対応出来ていませんが、よく使うであろう所は対応できていると思います
引きt魏の資料などを書く際に使ってみましたが、そこそこいい感じでWordにしてくれます
スクリプトなので改造すれば好きなようにカスタマイズが可能です
個人的にはテーブルに連番がつけれるように拡張したところと
テーブルの縦結合には対応していませんが、横の結合には対応したので階層構造を表すことも出来ます
箇条書きの階層に対応したところが気に入っています
これが出来ないからAsciidocを却下されていたので

== テーブルに連番をつける
optionsにautonumberを付けた場合1列目に連番を自動的に埋め込みます
[source,asciidoc]
----
.一覧サンプル
[cols="1,1,1,10,6,15", options="header,autonumber"]
|===

|#
3+|項目
|説明
|備考

|
3+大項目 ※2列-4列結合
|説明
|備考

|
|
2+|中項目 ※3列－4列結合
|説明
|備考

|
|
|
|小項目
|説明
|備考
|===
----

== Draw.io変換
システム構成図などをDraw.ioで書いて埋め込むことが出来ます
**__現在SVGには非対応 SVGにするとうまく埋め込まれません・・・__**

* Draw.ioサンプルコード

```
[drawio,generated-image-format="png",file="drawio/サンプル.drawio",caption="サンプル構成図"]
```

== 箇条書き
数字付き箇条書きは数字の連番の場合「1)」,「 1-1)」,「 1-1-1)」といった表記となります
箇条書きの場合は「・」,「・・」,「・・・」といった表記になります

== 拡張仕様一覧

本スクリプトが独自拡張または独自ルールとして実装している主な項目を示します。

[cols="2,4,4,6",options="header"]
|===
|機能
|入力例
|出力例
|注意点

|テーブル autonumber
|`[cols="1,3",options="header,autonumber"]`
|1列目の空セルに 1,2,3... を自動設定
|`options` に `autonumber` を含む場合のみ有効。`header` がある場合はヘッダ行を採番しません。

|章節項の番号付与
|`:sectnums:` を定義した見出し
|`1`, `1.1`, `1.1.1` 形式で見出し先頭に付与
|`sectnums` 未指定時は番号を付けません。見出しレベルが進むと下位番号はリセットされます。

|番号付きリストの番号付与
|`1.` や `..` を使ったリスト
|`1)`, `1-1)`, `1-1-1)`
|見出しやタイトルでカウンタをリセットします。レベルごとに連番を管理します。

|箇条書きインデント
|`*` / `-` と先頭スペースによるネスト
|`・`, `・・`, `・・・` 相当で段階表示
|先頭スペース2文字ごとに1レベルとして計算し、Word側の左インデントを段階的に増やします。

|リンク機能
|`https://...` / `link:...[]` / `<<...>>` / `xref:...[]`
|Wordのハイパーリンクとして出力
|内部リンクは `[[id]]` または `[#id]` でアンカー定義が必要。未解決時は通常テキストとして出力。
|===

=== 1. テーブル autonumber

==== 入力例

[source,asciidoc]
----
.一覧
[cols="1,3",options="header,autonumber"]
|===
|No|項目
||A
||B
||C
|===
----

==== 出力例

* ヘッダ行: `No / 項目`
* 本文1行目: `1 / A`
* 本文2行目: `2 / B`
* 本文3行目: `3 / C`

==== 注意点

* 先頭列が空欄の場合のみ自動採番します。
* 先頭列に値がある場合はその値を優先します。
* 自動採番列は右寄せで表示されます。

=== 2. 章節項（見出し）の番号付与

==== 入力例

[source,asciidoc]
----
:sectnums:

== 章
=== 節
==== 項
----

==== 出力例

* `1 章`
* `1.1 節`
* `1.1.1 項`

==== 注意点

* `:sectnums:` が未指定の場合、番号は付与しません。
* 見出しレベルが上がるたびに下位レベル番号はリセットされます。

=== 3. 番号付きリストの番号付与

==== 入力例

[source,asciidoc]
----
1. 手順
.. サブ手順1
.. サブ手順2
1. 次の手順
----

==== 出力例

* `1) 手順`
* `1-1) サブ手順1`
* `1-2) サブ手順2`
* `2) 次の手順`

==== 注意点

* レベル1は `n)`、レベル2以降は `n-m)` 形式です。
* 見出し・タイトル要素でリスト番号はリセットされます。

=== 4. 箇条書きのインデント

==== 入力例

[source,asciidoc]
----
* 項目
	* 子項目
		* 孫項目
----

==== 出力例

* `・ 項目`
* `・・ 子項目`
* `・・・ 孫項目`

==== 注意点

* 行頭スペース2文字を1レベルとして階層を判定します。
* Wordの左インデントはレベルに応じて増加します。

=== 5. リンク機能

==== 入力例

[source,asciidoc]
----
外部URL: https://example.com
外部URL(表示名): link:https://example.com[サンプルサイト]

[[table_sec]]
== 表セクション

内部リンク1: <<table_sec>>
内部リンク2: <<table_sec,表セクションへ移動>>
内部リンク3: xref:table_sec[表セクションへ移動]
----

==== 出力例

* 外部リンクはWord上でクリック可能なハイパーリンクとして出力されます。
* 内部リンクは該当アンカー位置へジャンプするハイパーリンクとして出力されます。

==== 注意点

* 内部リンクの参照先には、事前に `[[id]]` または `[#id]` を定義してください。
* 参照先アンカーが見つからない場合は、リンク文字列を通常テキストとして出力します。
