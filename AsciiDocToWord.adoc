== 目的

本ツールは AsciiDoc 形式の文書を Microsoft Word(.docx)形式 に変換するためのツールである。

本資料では、各AsciiDoc記述について以下を対で記載する。

* 入力（AsciiDoc記述例）
* 出力イメージ（Word変換結果イメージ）

== 推奨記述ルール

[cols="1,9",options="header,autonumber"]
|===
|No
|推奨事項

|
|テーブルには options="header" を付与する

|
|手順は番号付きリストを利用する

|
|補足説明には NOTE を利用する

|
|危険操作には WARNING を利用する

|
|長いコードは source ブロックを利用する

|
|表紙情報は属性定義を利用する
|===
